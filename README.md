# Weather App 🌦️

A simple weather application built using **HTML, CSS, JavaScript** and **OpenWeather API**.

## Features
- Dropdown with 50+ villages (Rajahmundry, Kakinada, Tuni, Diwancheruvu, etc.)
- Real-time weather data (Temperature, Humidity, Condition, Wind Speed)

## How to Run
1. Clone the repo
2. Open `index.html` in browser
3. Select a village → Click Search → View weather report
